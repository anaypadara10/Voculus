THE TECHNOLOGY

Discover the technology that brings VOCULUS to life.

Where Software Meets Hardware

VOCULUS brings together programming, voice recognition and electronics to create a calculator that responds to spoken mathematical expressions.

🐍

Python

Python handles speech recognition, processes the spoken mathematical expression and calculates the answer.

🔌

Arduino Mega

The Arduino Mega receives the required display instructions and controls the servo motors.

⚙️

14 Servo Motors

Fourteen servo motors move the display segments into the required positions to represent the answer.

🔢

Seven-Segment Display

The physical display uses arranged segments to show numerical answers clearly.

🎙️

Microphone

The microphone captures the user's spoken mathematical expression as the starting point of the process.

🔗

Software + Hardware

Python and Arduino work together so that a calculated result can appear on the physical display.

ONE PROJECT. MULTIPLE TECHNOLOGIES.

Voice Recognition + Python + Arduino Mega + Servo Motors = VOCULUS
