THE PROCESS BEHIND THE PROJECT

HOW IT WORKS

From spoken mathematics to a displayed answer — in a few simple steps.

Simple. Smart. Voice-powered.

VOCULUS takes a spoken mathematical expression, processes it using a computer program, and displays the calculated answer on a physical seven-segment display.

1

🎙️ Voice Input

The user speaks a mathematical expression into a microphone, such as “Twenty-five plus seventeen.”

2

💻 Speech Processing

Python processes the spoken words and converts the recognised expression into a form that can be calculated.

3

🧮 Calculation

The mathematical expression is evaluated to find the correct answer.

4

🔢 Answer Display

Arduino Mega controls the servo motors that move the segments of the physical display to show the result.

THE COMPLETE WORKFLOW

SEE IT IN ACTION

25 + 17 = 42

Spoken input → Processing → Calculation → Display

VOCULUS combines voice recognition, programming, electronics and mechanical movement to make calculation possible without a traditional keypad.
